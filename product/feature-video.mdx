This is the living spec for the video-editor feature, tracked in the **#feat-video** Slack channel and paired with this page under the [feature-channel workflow](/product/feature-channel-workflow). The doc is the source of truth: when Slack and this page disagree, this page wins.

## Current state

The channel was created on 2026-07-01 and this is the opening scaffold. The scope below is the initial feature list proposed by Petar and Joel and [shared by Eddie Wu](https://almanac-hq.slack.com/archives/C0BFCFCPUN4/p1782926268434989). This channel is still early: the build status of the individual editor surfaces listed below is being confirmed. Sections fill in as decisions land.

## Requested by Petar (2026-07-02)

Petar shared these as feature ideas, illustrated with example screenshots taken from other apps — they are not confirmed Blaze features. Each needs to be checked against the current editor first (an equivalent may already exist) and built if it doesn't.

| Feature | Notes |
| --- | --- |
| **Text panel + style presets** | Side panel with category tabs (All / Simple / Title / Lower Third / Other) and font/style presets. Verify whether an equivalent already exists in the editor; else build. Not yet tracked. |
| **Audio fade in/out** | Toggle with independent Fade In / Fade Out duration sliders on audio clips. Verify whether it already exists; else build. Not yet tracked. |
| **Audio panel (library + upload)** | Browse an asset library and upload audio: AI voice / upload tabs, voice cloning / voiceover, stock music. The stock-audio modal shipped as BLZ-15693 (done); confirm coverage and extend for library-browse + upload if needed. |
| **AI voice (text-to-speech)** | "Add Text-to-Speech": text input, language selector, and actor / voice-clone selection. Verify whether it already exists; else build. Not yet tracked. |
| **Video speed** | Simple speed slider, no speed ramps. Already tracked as BLZ-15857 (Backlog). |
| **GIF / animated-PNG element library** | Canva-style browsable library of animated elements. Scope pending Petar's confirmation; distinct from the existing animated-image pipeline (BLZ-15469). |

## Core features (requested)

The editor-basics set the team wants first:

| Feature | What it does |
| --- | --- |
| **Generate video in editor** | An entry point to generate a video from inside the editor. |
| **Captions from script** | Generate captions directly from the script. |
| **Captions from source** | Generate captions from an uploaded audio or video file. |
| **Splicing** | Cut and rejoin clips on the timeline. |
| **Color filters** | Apply color filters to video. |
| **Auto scene splicing** | Automatically splice scenes on import, driven via MCP. |

## Nice to have

- Speed up / slow down video. (Also captured under [Requested by Petar](#requested-by-petar-2026-07-02) — tracked as BLZ-15857.)
- Left-to-right timeline with named layers.
- More shape options.
- Select multiple layers from the timeline or canvas.

## Open questions

- Priority and sequencing across the core features — not yet decided.
- What the "generate video" entry point looks like (model, trigger, and UI).
- How much of scene splicing is automatic (MCP on import) versus manual on the timeline.
- Petar's screenshots were examples drawn from other apps, not Blaze features — so the whole batch under [Requested by Petar](#requested-by-petar-2026-07-02) needs an exists-vs-build check against the current editor before any work is scoped.
- Whether the requested GIF / animated-PNG element library means a Canva-style browsable library of GIFs / animated stickers, and whether that's feasible — distinct from the existing animated-image pipeline. Scope pending Petar's clarification.
